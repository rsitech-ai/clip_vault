# ClipVault Support

ClipVault is pre-1.0 software. Community support is best-effort and currently limited to the latest `main` branch on Apple-silicon Macs running macOS 15 or later.

## Bugs

After the public repository and support route are approved, use its bug-report issue form. Before filing:

1. Reproduce on the latest available commit or release.
2. Run `./script/test.sh` when you are working from source.
3. Include the macOS version, hardware architecture, ClipVault version/commit, exact steps, expected result, and actual result.
4. Remove clipboard contents, credentials, personal data, signing identities, full local paths, and proprietary material from screenshots and logs.

## Feature requests

After that route is approved, use the feature-request issue form and describe the repeated user job, current workaround, desired outcome, and privacy or compatibility impact.

## Security and privacy

Do not use a public issue for vulnerabilities or sensitive privacy failures. Follow [SECURITY.md](SECURITY.md).

The canonical support URL is `https://github.com/rsitech-ai/clip_vault/blob/main/SUPPORT.md`. Repository issue forms become the public support route only after the repository is approved for public visibility.

## App Store and account support

This repository cannot resolve Apple Developer Program membership, certificate access, App Store Connect roles, billing, purchase, or review decisions for third parties.
