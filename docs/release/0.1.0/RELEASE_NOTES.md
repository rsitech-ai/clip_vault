# Release Notes — 0.1.0 (1)

Initial Mac release candidate:

- Local clipboard history for text, code, links, files, rich text, and screenshots.
- Local OCR, search, organization, notes, tags, pinning, cleanup, and copy-back.
- Hierarchical Move to Collection menus and single-clip drag-and-drop onto custom sidebar collections.
- Fast collection assignment and move operations that update only the affected clips, including large libraries and smart-folder workflows.
- Efficient Finder file and folder queueing without redundant rich-pasteboard decoding.
- Local Foundation Models actions when available.
- Explicit clipboard-capture consent, pause, and revoke controls.
- Encrypted local payload and detail storage with Keychain-backed keys.
- Menu bar All Clips, Dock, Settings, and responsive workspace surfaces.

This copy is a draft and requires product-owner approval before App Store use.
