# App Review Notes Draft

ClipVault is a local-first clipboard history workspace for macOS. On first launch, clipboard watching is paused and a disclosure explains the data handled, local OCR, local encrypted storage, default retention, and sensitive-item filtering. Reviewers can choose Not Now, reopen the disclosure with Start Capture, accept it, pause capture, or revoke consent in Settings.

The app stores clipboard payloads, OCR text, titles, tags, notes, and folders locally. It has no account, backend, analytics, tracking, advertising, purchases, subscriptions, or active cloud AI provider. Foundation Models actions and OCR run on device. Individual and bulk deletion are available.

Suggested review flow: accept capture disclosure; copy a unique text item; confirm it appears once; copy it again and confirm its count increases; search; add a note/tag; pause capture; revoke consent in Settings; relaunch and confirm disclosure is required again.

No demo credentials are required. The screenshot shortcut invokes the macOS system screenshot command; the user chooses/cancels the capture interactively.
